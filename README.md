## TIG2GD
This is a Geode mod that allows you to import levels from *The Impossible Game* into *Geometry Dash*. Importing is identical to how it works in TIG, you select the folder that contains your level (except on iOS where you have to select the level file inside of the folder due to Geode related issues regarding the folder picker), and it'll load it into your save file. It won't (and cannot) load songs, nor will the physics be 100% accurate, so some levels may need some tuning-up after import.
